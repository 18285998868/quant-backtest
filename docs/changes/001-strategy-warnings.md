# 001 策略告警通道

## 动机

S3 的截面动量在逆波动率权重无法计算时,需要按设计回退等权并写入报告 `warnings`。
原 `Strategy` trait 只有 `on_bar`,策略没有把运行期告警交给引擎的通道。

## 影响范围

- `Strategy` trait 新增带默认实现的 `take_warnings()`。
- 引擎在每次 `on_bar` 后收集并追加到 `BacktestResult.warnings`。
- 不改变 `on_bar` 签名,现有自定义策略无需改动。

## 替代方案

1. 给 `on_bar` 增加 `warnings: &mut Vec<String>` 参数。会破坏所有现有策略实现,弃用。
2. 让策略直接返回结果结构。改动面更大,且与 `out` 的就地复用风格不一致,弃用。
3. 由引擎检测非法权重并告警。引擎不知道策略内部为什么回退,无法给出可操作原因,弃用。

## 回退计划

删除 `take_warnings` 默认方法与引擎收集逻辑即可;不涉及持久化格式。
